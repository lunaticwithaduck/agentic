## Outcome

Completed on 2026-05-18. The OG card now carries the live constitution quote underneath the metric row, rendered as italic small text in `--ink-tertiary`. `truncateSnippet(s, 110)` cuts on word boundaries and appends `…` to keep the line within the card width. Only renders in `og` mode so the live page (which already has the constitution panel in the sidebar) doesn't duplicate it.

**Test determinism**: the constitution fetcher hits a real GitHub raw README which could change underneath the byte snapshot. Added `PIN_CONSTITUTION_SNIPPET` env override — when set, `getConstitutionSnippet` returns that literal value without making the network call. The Playwright webServer config sets this to the AUTONO fallback text, so OG byte snapshots stay stable regardless of upstream README changes. Live deploys (no env var set) hit the real URL and cache normally.
