## Goal
SHADOW signals are internal paper-trades that should never be indexed by Google. Filtering them from sitemap.xml (prior task) prevents direct discovery, but `/signals` listing page still links to them — so Googlebot can crawl them via internal links. Add `<meta name="robots" content="noindex,nofollow">` to each SHADOW signal's HTML so even crawled pages are excluded from the index.

## Outcome
- Injected `<meta name="robots" content="noindex,nofollow">` into the `<head>` of all 20 SHADOW signal HTML files (inserted on the line immediately after `<meta charset="UTF-8">`)
- Idempotency guarded — script skips files that already have a `name="robots"` tag
- Verified post-condition: 20 SHADOW files now have the tag, zero non-SHADOW signal files were modified
- `nofollow` included alongside `noindex` so Googlebot also doesn't follow outbound links from these paper-trade pages (they often reference Polymarket/Kalshi market URLs)
- NOT_PUBLISHED signals deliberately left untouched — they'll flip to PUBLISHED/WIN/LOSS later and need to be indexable at that point

## Caveats
- This is a one-shot edit on the rendered HTML. If signal pages are regenerated by a build step (TBD — generator not located in this session), the next regeneration will overwrite this tag unless the generator template is updated to emit it for SHADOW status. User should commit current files and, when ready, update the signal-page generator to make the noindex permanent.
